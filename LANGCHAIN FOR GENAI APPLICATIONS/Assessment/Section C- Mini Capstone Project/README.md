QuickBite AI - Intelligent Food Delivery Assistant

Features:
1. Streamlit Chat Interface
2. Delivery Time Prediction API
3. Menu Recommendation System
4. Conversation Memory
5. User Preferences Sidebar
6. Clear Chat Functionality

Run:

1. Train model:
python train_model.py

2. Start Flask API:
python delivery_predict_api.py

3. Start Streamlit:
streamlit run app.py
